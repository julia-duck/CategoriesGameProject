# Categories Game

### A game where you find the word that is out of place.
Gameplay: the player is given a list of words picked from a random category (separate text files store words from different categories). One of the words picked is from a different category. The user then guesses which word does not fit and isn't from the same category as the rest.

By [@grassybox](https://github.com/grassybox) and [@julia-duck](https://github.com/julia-duck) using Java and VSCode
